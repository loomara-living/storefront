# Loomara Living

Offline-first static website for **Loomara Living**.

## Preview locally

Run the bundled preview server with Node.js:

```sh
node preview-server.mjs
```

Then open <http://127.0.0.1:4173>.

## Pages

- Home
- Collection
- Our Story
- Contact

The collection and newsletter are intentionally presented in preview mode until real product data and a production signup workflow are connected.
